Orion v0.4.0 — Workspaces can be renamed.

Install over your existing copy. Your data, workspaces, resources, scripts and timers are untouched.

## Rename a workspace

Hover a workspace in the sidebar and a pencil appears beside the bin. Click it — or just double-click the workspace — and type the new name. Enter saves it, Escape leaves it as it was.

Until now a name was fixed when you created it. Fixing a typo meant deleting the workspace and building it again from nothing, losing its resources, scripts, tasks and every hour you had logged against it. That is no longer the trade.

Everything follows the new name, including Quick Launch and search, and the workspace keeps its constellation — the figure is drawn from the workspace itself, not from what it is called.

## Smaller things

- A rename shows up instantly and is undone by itself if it cannot be saved, so the sidebar never shows a name the database does not have.
- The sidebar stops trying to reorder itself while you are typing in it.

## Coming

macOS support is built and is being tested on real hardware. It is not in this release. When it lands, the same backup file will carry a setup between a Windows machine and a Mac in either direction, with anything the other platform cannot run kept intact rather than dropped.

## Upgrading

Install over your existing copy, or let the in-app updater offer it to you.
